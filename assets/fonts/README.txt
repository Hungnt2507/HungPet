Tải font Be Vietnam Pro tại:
https://fonts.google.com/specimen/Be+Vietnam+Pro

Sau đó chép file BeVietnamPro-Regular.ttf vào thư mục này (assets/fonts/) trước khi chạy build_exe.bat.
Nếu chưa chép file, ứng dụng sẽ tự động dùng font Segoe UI có sẵn trên Windows để hiển thị tiếng Việt không bị lỗi dấu.
